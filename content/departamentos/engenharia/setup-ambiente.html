Como configurar o ambiente local

Este é um documento de exemplo que acompanha a instalação. Ele existe para você ver como uma documentação aparece no portal — pode editá-lo pela interface ou apagar o arquivo e o registro some da listagem no próximo sync.

Pré-requisitos

  • Node.js 20 ou superior
  • Docker e Docker Compose (ou um PostgreSQL 17 acessível)

Passo a passo

  1. Copie .env.example para .env.
  2. Gere um segredo com openssl rand -base64 32 e cole em NEXTAUTH_SECRET.
  3. Suba o banco com npm run db:up.
  4. Aplique as migrations com npm run db:migrate.
  5. Rode npm run dev e abra http://localhost:3000.

Problemas comuns

Se docker ps retornar permission denied, adicione seu usuário ao grupo docker e faça logout/login.
